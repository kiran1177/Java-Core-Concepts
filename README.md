## ▶️ How to Run

1. Clone or download this repository.

2. Open the folder containing a Java program.

3. Open a terminal in that folder.

4. Compile the program:

   ```bash
   javac ProgramName.java
   ```

5. Run the program:

   ```bash
   java ProgramName
   ```

Replace `ProgramName` with the Java class name.
